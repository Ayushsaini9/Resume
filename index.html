About

I got into programming because I wanted to understand how websites worked. Not a grand origin story - I was just curious why some sites loaded instantly and others felt broken. That curiosity turned into building full-stack apps with React and Node.js.

I'm not the kind of developer who lists every framework they've touched. I pick what I need, learn it properly, and build with it. Right now that's React on the front, Node and Express on the back, and MongoDB or MySQL depending on what the project needs.

I think most developers (myself included) jump to frameworks too early without really understanding vanilla JavaScript. I'm still working on that.

Selected work

PYQ Analysis Website

This started as a frustration. I was studying for exams and realized I was wasting time on topics that rarely appeared. So I built a tool that analyzes previous year questions to find patterns - repeated topics, frequency trends, and difficulty distribution.

Still a work in progress. The trend detection needs better algorithms, and the UI needs a redesign. But it solves my original problem, and a few classmates use it now.

React.js Node.js Analytics

Online Book Store

A full-stack e-commerce project. I followed a MERN stack tutorial for the initial setup, then extended it with search filters, a proper cart system, and user authentication.

The hardest part was getting the cart state to persist between page refreshes. I used localStorage as a workaround, which I know isn't ideal for production.
