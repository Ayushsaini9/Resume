# Ayush Saini — Portfolio

A personal portfolio website for Ayush Saini, a B.Tech Information Technology student and full-stack developer from SKIT Jaipur.

The website showcases my skills, education, projects, current learning goals, and contact information through a clean editorial-style design.

## Features

- Responsive portfolio layout
- Smooth scrolling navigation
- About, Skills, Projects, Education, and Contact sections
- Scroll reveal animations
- Custom cursor interaction
- Reduced-motion support
- Responsive typography and layout
- Project showcase with images
- Mobile-friendly design

## Projects

### PYQ Analysis Website

A tool that analyzes previous-year questions to identify repeated topics, frequency trends, and difficulty patterns.

### Online Book Store

A full-stack e-commerce project featuring book search, filters, cart functionality, and user authentication.

## Technologies Used

- HTML5

- JavaScript
- Google Fonts

- Responsive Web Design
